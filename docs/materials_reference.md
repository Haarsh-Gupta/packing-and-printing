# Printing & Packaging Materials Reference

> **Best Practice for "Brand" Tracking:** Only track the brand when it technically matters for the process (e.g., Inks, CTP Plates, Specialty UV Coatings). For commodity items (like Paper, Kraft Board, Corrugated Sheets), the technical specs (GSM, Burst Factor) matter more, and tracking brand just adds unnecessary data entry overhead.
>
> **Best Practice for Liquid Tracking (Glues, Chemicals):** Liquids are often procured in Liters but consumed on the shop floor by Weight (Kg) using a weighing scale. This is much easier for the factory workers than measuring sticky liquids by volume. For these items, define the **Density (Kg/L)** attribute once during material creation so the system can convert Liters to Kg seamlessly.
